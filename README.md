# Patient-Health-Monitoring-System
An ESP32 based Patient Health Monitoring System designed to monitor patient health parameters in real time using sensor data. The system provides instant visual and audio alerts for abnormal conditions, enabling efficient and reliable health status monitoring. 

##Components used:
-ESP32 DevKit V1
-DHT22 Sensor
-LED
-Buzzer

##Features:
-Real time monitoring
-Automatic alerts
-Easy to simulate using Wokwi
